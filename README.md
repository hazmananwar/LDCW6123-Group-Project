# LDCW6123-Group-Project
Repository to store all files regarding LDCW6123 group project

To run the program, simply download all 3 files (shopping_cart_summary.py, models.py & pricing.py) and store them into one folder. Then, open them using an IDE for Python 3.10+ (or any IDE software that can run Python 3.10+) and run the main class file (shopping_cart_summary.py).
